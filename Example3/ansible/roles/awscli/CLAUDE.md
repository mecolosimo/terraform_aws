# AWS CLI Installation Role

Generated by Claude modified by me. This role installs the AWS CLI and related
Python packages (boto3, botocore) on target hosts.

## Supported Platforms

**Debian-based:**
- Ubuntu 18.04, 20.04, 22.04+
- Debian 9, 10, 11+

**RedHat-based:**
- CentOS 7, 8+
- Red Hat Enterprise Linux (RHEL) 7, 8+
- Amazon Linux 2 (uses yum package manager)

**Detection:** Uses `ansible_os_family` fact
- `Debian` → uses `apt`
- `RedHat` → uses `yum` (includes CentOS, RHEL, Amazon Linux)

## Role Variables

### Required Variables
None - all variables have sensible defaults.

### Optional Variables

| Variable | Default | Description |
|----------|---------|-------------|
| `awscli_version` | `latest` | AWS CLI version to install |
| `awscli_user` | `{{ ansible_user }}` | User who will use AWS CLI |
| `awscli_pip_executable` | `pip3` | Python pip executable to use |
| `install_boto3` | `true` | Install boto3 package |
| `install_botocore` | `true` | Install botocore package |
| `create_aws_config` | `true` | Create ~/.aws directory |
| `aws_region` | `{{ aws_region }}` | Default AWS region |
| `aws_output_format` | `json` | Default output format |

## Usage

### Basic Installation

```yaml
- name: Install AWS CLI on all hosts
  hosts: all
  become: yes
  roles:
    - awscli
```

### Install Specific Version

```yaml
- name: Install AWS CLI v1
  hosts: all
  become: yes
  vars:
    awscli_version: "1.32.45"
  roles:
    - awscli
```

### With Custom Region

```yaml
- name: Install AWS CLI with custom region
  hosts: webservers
  become: yes
  vars:
    aws_region: us-west-2
  roles:
    - awscli
```

## Tasks

The role performs these tasks in order:

1. Display host information
2. Update package cache (OS-specific)
3. Install pip and dependencies
4. Upgrade pip to latest version
5. Install AWS CLI
6. Install boto3 and botocore (optional)
7. Verify AWS CLI installation
8. Create AWS config directory

## Tags

Run specific tasks with tags:

```bash
# Only verify installation
ansible-playbook -t verify

# Skip package updates
ansible-playbook --skip-tags packages

# Only install AWS CLI
ansible-playbook -t awscli
```

Available tags: `debug`, `packages`, `dependencies`, `pip`, `awscli`, `verify`, `config`, `info`, `summary`

## Handlers

- `verify aws cli` - Triggered after AWS CLI installation

## Examples

### Deploy to All Hosts

```bash
ansible-playbook playbooks/deploy-awscli.yml
```

### Deploy to Specific Group

```bash
ansible-playbook playbooks/deploy-awscli.yml --limit webservers
```

### Deploy to Single Host with Verbose Output

```bash
ansible-playbook playbooks/deploy-awscli.yml --limit web01 -vvv
```

### Check Mode (Dry Run)

```bash
ansible-playbook playbooks/deploy-awscli.yml --check
```

## Dependencies

None - role is self-contained.
